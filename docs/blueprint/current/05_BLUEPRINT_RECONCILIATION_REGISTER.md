# Existing Blueprint Reconciliation Register

## Status labels

- **GOVERNING** — current top-level direction.
- **AUTHORITATIVE** — may be implemented as written unless a governing document narrows it.
- **AUTHORITATIVE WITH AMENDMENTS** — core design remains valid; listed conflicts are superseded.
- **FUTURE CONTRACT** — valid target for a later wave, not current implementation authority.
- **PARTIALLY SUPERSEDED** — useful detail remains, but inputs/order/ownership require revision.
- **HISTORICAL REFERENCE** — context only; not implementation authority.

## Rule for future documents

Every new blueprint or implementation brief must identify:

```text
its governing parent
which existing documents it amends
which fields/processes it owns
whether it is planning or implementation
its authority level
its promotion and rollback boundary
```

No new document may quietly establish a competing causal chain.
